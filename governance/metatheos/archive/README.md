# Archive

This directory contains historical documentation and progress logs from the Metatheos development process.

## Purpose

These files have been archived as part of the **v2.0 Consolidation Release** (Phase 1.2: Documentation Consolidation).

All relevant information has been consolidated into the core documentation:
- `/README.md` — Project overview and quick start
- `/docs/ARCHITECTURE.md` — Technical design
- `/docs/USER_GUIDE.md` — Usage instructions
- `/docs/CONTRIBUTING.md` — Development guidelines
- `/docs/CHANGELOG.md` — Version history

## Contents

### `/progress-logs/`

Development progress logs from Phases 0-4:
- Setup guides (AI, Ollama, Icons)
- Implementation notes
- Feature completion logs
- Architecture decision records
- Performance optimization plans
- Dashboard design docs

**Status**: Historical reference only
**Maintained**: No
**Relevance**: Context for understanding development history

## Accessing Historical Information

If you need information from these logs:

1. **Check core docs first**: Most information has been consolidated
2. **Search archive**: Use grep or file search if needed
3. **Contact team**: Ask maintainers if documentation is unclear

```bash
# Example: Find references to SurrealDB setup
grep -r "SurrealDB" archive/progress-logs/
```
