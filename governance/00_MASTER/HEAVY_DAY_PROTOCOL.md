# Heavy Day Protocol (🟥)

**Mode:** Deep canonical / architectural work.
**Target Duration:** 8–12 hours.
**Focus:** SINGLE AXIS ONLY.

> **Philosophy:** "Progress is measured in resolved ambiguity, not lines of code."

---

## 1. Entry Checklist
Before starting, verify:
- [ ] **Sleep:** Am I rested enough for complex logic?
- [ ] **Clarity:** Do I know *exactly* what problem I am solving?
- [ ] **Scope:** Is the scope bounded to ONE Focus Axis? (e.g., ONLY Engine, or ONLY Canon).
- [ ] **Environment:** Notifications off. Distractions removed.

## 2. The Single-Focus Rule
*   You must choose **ONE** Focus Axis (e.g., PROTOCOL).
*   You may NOT switch axes midday (e.g., don't switch from writing Protocol to debugging CSS).
*   If you get blocked, write a "Blocker Note" and stop. Do not context switch to "easy work".

## 3. Execution Loops
Work in 3-4 hour deep blocks.
*   **Block 1:** Architecture / Truth / Design.
*   **Block 2:** Implementation / Writing / Coding.
*   **Block 3:** Verification / Edge-cases.

## 4. Stop Conditions
Stop immediately if:
*   You are making "temporary" decisions to save time.
*   You are confused for more than 45 minutes without writing down *why*.
*   You violate a Canon to make a feature work.
*   You hit the 12-hour mark (Hard Stop).

## 5. Mandatory Shutdown Ritual
1.  **Freeze State:** Commit code or save all notes.
2.  **Log Divergence:** Note anywhere you strayed from the plan in your Daily Note.
3.  **Define Tomorrow:** Write the single sentence objective for tomorrow.
4.  **Disengage:** Walk away from the screen. The machine is off.
