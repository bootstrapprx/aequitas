## 🌅 Morning Sequence

**Step 1: Context**
- [ ] Check [[CALENDAR|Master Calendar]] for today's Mode.
- [ ] Check [[Aequitas Roadmap Master#Now (Manual)|Roadmap NOW Panel]] for immediate priorities.
- [ ] Review [[01_DAILY/YYYY-MM-DD|Yesterday's Log]] (Cmd+O -> type date).

**Step 2: Initialize**
- [ ] **Create Today's Note**: Cmd+N -> Type `YYYY-MM-DD` -> Apply Template `_TEMPLATE — Daily`
- [ ] **Set Mode**: Define `mode` (🟥/🟩/🟦) in frontmatter based on Calendar.
- [ ] **Select Primary Protocol**:
    - 🟥 **Heavy**: [[HEAVY_DAY_PROTOCOL]]
    - 🟩 **Light**: [[LIGHT_DAY_PROTOCOL]]
    - 🟦 **Review**: [[REVIEW_DAY_PROTOCOL]]
